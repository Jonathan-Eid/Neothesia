# Shortcuts

### In Player

| Key                 | Action                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Left/Right**      | Rewinds (shift makes it faster)                                                                            |
| **Up/Down**         | Changes the speed (shift makes it faster)                                                                  |
| **-/+**             | Adjusts sound offset/delay (shift makes it faster) - offset is just used if your headset is lagging behind |
| **PageUp/PageDown** | Adjusts animation/waterfall speed                                                                          |
| **a**               | Shows/hides the theory panel                                                                               |
| **. / ,**           | Steps to the next/previous note of the song, pausing playback                                               |
| **k / K**           | Steps the left hand forward/back                                                                            |
| **l / L**           | Steps the right hand forward/back                                                                           |
| **Space**           | Leaves step mode and resumes playback                                                                       |

A track set to **Human** in the track picker pauses the song until you play its next note(s) on a MIDI keyboard, or the PC-keyboard fallback below (mute the hand you're not practicing to remove it from the waterfall and the requirement).

### In Main Menu

| Key            | Action                  |
| -------------- | ----------------------- |
| **Tab**        | Open file select dialog |
| **Left/Right** | Change output           |
| **Enter**      | Start playing           |
